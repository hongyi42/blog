# Hongyi's Digital Garden

A public, growing collection of notes on markets and quantitative finance, statistics and
inference, macroeconomics, and a rotating cast of side interests — published in the open as a
learn-in-public [digital garden](https://jzhao.xyz/posts/networked-thought).

- **Live site:** https://hongyi42.github.io/blog

## How it works

Notes are written in a private [Obsidian](https://obsidian.md) vault. Only the notes in one
folder are ever published; everything else stays private. Publishing mirrors that folder into
`content/` and pushes to `main`, and GitHub Actions builds and deploys the site to GitHub Pages.

See [START-HERE.md](START-HERE.md) for the full workflow and maintenance guide.
